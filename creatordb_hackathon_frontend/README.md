# clearHub

An influencer intelligence platform built with Next.js 14 and TypeScript. Find creators, explore competitor brands, and generate AI-powered brand comparison reports.

---

## Prerequisites

| Tool | Version | Install |
|------|---------|---------|
| Node.js | 18+ | https://nodejs.org |
| Claude Code CLI | latest | `npm install -g @anthropic-ai/claude-code` |

The Claude Code CLI (`claude`) must be available in your `PATH` — it is used at runtime to generate brand comparison reports.

Verify both are installed:

```bash
node -v
claude --version
```

---

## Setup

### 1. Clone and enter the project

```bash
git clone https://github.com/alalachin/creatordb_hackathon.git
cd creatordb_hackathon/creatordb_hackathon_frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env.local` file in this directory:

```bash
cp .env.local.example .env.local   # if example exists, or create manually
```

`.env.local` contents:

```env
# CreatorDB API key
CREATORDB_API_KEY=your_api_key_here

# Absolute path to the project root (one level above this folder)
# Used by API routes to read the CSV data and write output reports
PROJECT_ROOT=/absolute/path/to/creator_hackathon
```

> **Important:** `PROJECT_ROOT` must be the absolute path to the repo root — the folder that contains `resource/`, `output/`, and `images/`. Example: `/Users/yourname/creator_hackathon`

### 4. Create the output directory

```bash
mkdir -p ../output
```

Reports generated by Claude are cached here as `.html` files.

## Features

| Page | Path | Description |
|------|------|-------------|
| Home | `/` | Landing page with feature overview |
| Competitors | `/entity-explorer` | Browse brands by category |
| Brand Selection | `/brand-information?category=Luxury` | Pick 2 brands to compare |
| Brand Comparison | `/brands-comparison?brandA=X&brandB=Y` | AI report (cached after first run) |
| Find Creators | `/find-creators` | Search creators by product type, budget, and filters |

---

## How brand comparison works

1. Select a category in **Competitors**, then pick any 2 brands
2. Click **Compare Brands** — the app checks `../output/{BrandA}_{BrandB}.html` for a cached report
3. If no cache exists, it calls `claude --dangerously-skip-permissions` with a prompt containing real demographic data from the CSV
4. The generated HTML report is cached to disk and rendered in an iframe
5. Subsequent requests for the same pair are served instantly from cache

Report generation can take up to **10 minutes** depending on Claude's response time.
